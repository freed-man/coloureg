How to find your car's paint code

Your car's paint code is on the vehicle identification plate, most often in the driver's door shut. If the plate is missing or unreadable, enter your registration above and we will look the code up from the manufacturer's build sheet for that car.

Every car leaves the factory with a paint code: a short string, usually three to seven characters, that identifies the exact colour it was sprayed in. A body shop or paint supplier mixes from that code. The colour name on its own is not enough, because manufacturers reuse names across shades and markets.

Where the code is on your car

It is printed on the vehicle identification plate: a sticker or a riveted metal plate, not something stamped into a panel. Look in the driver's door shut first, then the boot floor beside the spare wheel, then the passenger door shut, then under the bonnet near the slam panel. It sits near the VIN, often labelled Colour, Paint, C/TR, EXT or just a bare code.

If the plate is missing or unreadable

Plates get painted over, corroded, or removed with the panel they were on. That is what this tool is for: enter the registration and we look the code up from the manufacturer's own build sheet for that car, using the registration to find the VIN and the VIN to find the colour.

What the code looks like

Format varies by manufacturer, which is why a code that looks wrong often is not. Toyota and Vauxhall use three characters, like 040 for Super White or GAZ for Summit White. Honda uses a letter and digits, such as NH731P for Crystal Black Pearl. VW and Audi prefix theirs with an L, as in LY9T for Mythos Black. Ford uses both a short and a long form of the same code: 7VTA and 7VTAWWA are both Frozen White. Around nine in ten codes are between three and seven characters.

Finding the paint code from a VIN

The paint code is not encoded in the VIN itself, so it cannot be worked out from the characters alone. What the VIN does is identify the exact car on the manufacturer's system, and the build sheet for that car carries the colour it was sprayed in. That is the route a registration lookup takes: the registration finds the VIN, and the VIN finds the paint code. Most cars built since 1981 carry a seventeen-character VIN; older vehicles and some imports use a shorter chassis number instead.

Why the code matters more than the colour name

Two cars described as white on the V5C can be entirely different paints, and a name can mean different things in different markets: the same Mitsubishi paint is Silky White Pearl in the UK and Diamond White Pearl in the US. The code is what a supplier mixes from, so it is the part worth getting right.

If the code is faded, painted over or missing

Plates corrode, get painted over during a repair, or go with the panel they were riveted to. A half-readable code is worse than none, because a single wrong character is a different colour: on a Ford the difference between PN4DQ and PN4GZ is dark grey against blue. If you cannot read every character with confidence, look it up by registration instead of guessing.

Touch-up paint and what to order

For a stone chip or a key scratch, the paint code is what a supplier needs to mix a touch-up pen, brush bottle or aerosol. Give them the code rather than the colour name. If the finish is a pearl or a tri-coat, say so: those are sprayed in two or three stages and a single-stage match will not blend, so a body shop should spray a test card before touching the panel.

Where to look on common makes

Volkswagen, Audi, SEAT and Skoda put it in the boot, on the floor or in the spare wheel well, and older ones often repeat it in the service book. Ford, Vauxhall, Toyota, Honda, Nissan and Mazda are usually in the driver's door shut or on the B-pillar. BMW and Mercedes are commonly under the bonnet, on the slam panel or a strut tower, though some BMWs use the boot instead. Land Rover and Jaguar vary by age and are worth checking under the bonnet and both door shuts.

If none of those turn it up, the plate may have been painted over or lost with a replaced panel, and a registration lookup is quicker than continuing to search.

Resprays, wraps and special-order paint

A paint code describes the original factory colour. If a car has been resprayed a different colour the code will not match what is on it now. A vinyl wrap does not change the paint underneath, so the original code still applies once it comes off. A small number of cars were painted to special order, and their plate carries a placeholder rather than a colour code; in that case the real colour is on the build sheet and we look it up manually.
