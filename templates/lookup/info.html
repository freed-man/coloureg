About

coloureg helps you find your car's factory paint code by registration. Just type in your reg and we'll query the manufacturer's database to pull the colour code straight from the source. If our automated lookup can't reach the manufacturer's servers in time, we'll do a manual search and email the code to you within 12 hours. The site is in beta, actively being developed, so if you spot anything off or have suggestions, drop us a message below.
